## ⚠️ RÈGLES D'OR AVANT DE COMMENCER

1. Toujours créer le `.gitignore` AVANT le premier `git add .`
2. Ne jamais mettre de guillemets dans le `.gitignore`
3. Ne jamais tracker `venv/`, `data/` ou `__pycache__/`
4. Toujours vérifier le compte GitHub actif avant de pousser

---

## 📁 ÉTAPE 0 — Créer le .gitignore EN PREMIER

Créer un fichier `.gitignore` à la racine du projet avec ce contenu
(sans guillemets, sans espaces autour) :

```
venv/
env/
data/
__pycache__/
*.zip
*.pyc
.ipynb_checkpoints/
*.txt.zip
```

## 🔴 ERREURS FRÉQUENTES ET SOLUTIONS

---

### ❌ ERREUR 1 — remote origin already exists
```
error: remote origin already exists.
```

**Cause :** Un remote est déjà configuré (ancien projet ou ancienne tentative)

**Solution :**
```bash
git remote remove origin
git remote add origin https://github.com/KaynorData/nom-du-projet.git
git remote -v
```
> `git remote -v` permet de vérifier que le bon lien est configuré

**Puis continuer avec :**
```bash
git push -u origin main
```

---

### ❌ ERREUR 2 — Permission denied (mauvais compte)
```
remote: Permission to KaynorData/projet.git denied to konatebeh20.
fatal: unable to access '...': The requested URL returned error: 403
```

**Cause :** Git utilise un autre compte GitHub (ton ancien compte perso)

**Solution :**
```bash
# Étape 1 — Changer la configuration globale
git config --global user.email "kaynordata@gmail.com"
git config --global user.name "KaynorData"

# Étape 2 — Supprimer les identifiants mémorisés Windows
# Va dans : Panneau de configuration
#         → Gestionnaire d'informations d'identification
#         → Informations d'identification Windows
#         → Cherche "github.com"
#         → Clique sur Modifier ou Supprimer
#         → Supprime l'entrée

# Étape 3 — Pousser à nouveau (un navigateur s'ouvrira)
git push -u origin main
```
> Connecte-toi avec le compte KaynorData quand le navigateur s'ouvre

---

### ❌ ERREUR 3 — Fichier trop lourd (100MB+)
```
remote: error: File data/fichier.txt is 128.00 MB
remote: error: GH001: Large files detected.
```

**Cause :** Un fichier dépasse la limite de 100MB de GitHub

**Solution :**
```bash
# Étape 1 — Vérifier que data/ est dans le .gitignore
# Ouvre .gitignore et vérifie que la ligne "data/" est présente

# Étape 2 — Retirer le fichier du suivi Git
git rm -r --cached data/

# Étape 3 — Commiter la correction
git add .
git commit -m "fix: exclure data/ - fichier trop lourd"

# Étape 4 — Pousser
git push -u origin main
```

> ⚠️ `git rm --cached` ne supprime PAS le fichier de ton PC
> Il dit juste à Git de l'ignorer. Ton fichier reste sur ton disque.

---

### ❌ ERREUR 4 — venv/ tracké par Git (trop de warnings LF/CRLF)
```
warning: in the working copy of 'venv/Lib/site-packages/...'
LF will be replaced by CRLF...
(des centaines de lignes)
```

**Cause :** Le dossier `venv/` a été ajouté avant la création du `.gitignore`

**Solution :**
```bash
# Étape 1 — Retirer venv du suivi Git
git rm -r --cached venv/

# Étape 2 — Vérifier que venv/ est dans .gitignore
# (sans guillemets)

# Étape 3 — Commiter
git add .
git commit -m "fix: supprimer venv du suivi Git"

# Étape 4 — Pousser
git push -u origin main
```

---

### ❌ ERREUR 5 — pathspec did not match any files
```
fatal: pathspec 'venv/' did not match any files
```

**Cause :** Le dossier n'est pas tracké par Git (déjà ignoré ou déjà retiré)

**Solution :** C'est une bonne nouvelle — rien à faire.
```bash
# Vérifier ce qui est tracké
git status

# Si venv/ et data/ n'apparaissent pas → tout est bon
# Continuer directement avec :
git add .
git commit -m "fix: message de commit"
git push -u origin main
```

---

### ❌ ERREUR 6 — .gitignore avec guillemets (règles ignorées)

**Cause :** Le `.gitignore` a été créé avec des guillemets autour des chemins

**Mauvais .gitignore :**
```
"venv/"
"data/"
"__pycache__/"
```

**Bon .gitignore :**
```
venv/
data/
__pycache__/
*.zip
*.pyc
.ipynb_checkpoints/
```

**Solution :**
```bash
# Ouvrir .gitignore dans VS Code
# Supprimer tous les guillemets
# Sauvegarder avec Ctrl+S
# Puis :
git add .gitignore
git commit -m "fix: corriger .gitignore - supprimer guillemets"
git push -u origin main
```

---

### ❌ ERREUR 7 — branch main vs master
```
error: src refspec main does not match any
```

**Cause :** Git utilise `master` comme branche par défaut sur certaines versions

**Solution :**
```bash
# Vérifier la branche actuelle
git branch

# Si tu vois "master" au lieu de "main" :
git branch -M main
git push -u origin main
```

---

### ❌ ERREUR 8 — rejected, non-fast-forward
```
! [rejected] main -> main (non-fast-forward)
hint: Updates were rejected because the tip of your current branch is behind
```

**Cause :** Le repo GitHub a des commits que tu n'as pas en local
(Ex: tu as créé un README directement sur GitHub)

**Solution :**
```bash
# Récupérer les changements distants d'abord
git pull origin main --allow-unrelated-histories

# Puis pousser
git push -u origin main
```

## 🔄 PROCESSUS POUR CHAQUE NOUVEAU PROJET

```bash
# 1. Créer le dossier
mkdir nom-du-projet
cd nom-du-projet

# 2. Créer l'environnement virtuel
python -m venv venv
venv\Scripts\activate

# 3. CRÉER LE .gitignore EN PREMIER (avant tout)
# Contenu : venv/ | env/ | data/ | __pycache__/ | *.zip | *.pyc

# 4. Installer les bibliothèques
pip install pandas matplotlib seaborn jupyter

# 5. Générer requirements.txt
pip freeze > requirements.txt

# 6. Faire son travail (notebook, scripts, etc.)

# 7. Initialiser Git
git init

# 8. Configurer le compte
git config --global user.email "kaynordata@gmail.com"
git config --global user.name "KaynorData"

# 9. Vérifier le statut
git status

# 10. Ajouter et commiter
git add .
git commit -m "feat: description du projet"

# 11. Connecter GitHub et pousser
git remote add origin https://github.com/KaynorData/nom-du-projet.git
git push -u origin main
```

## 📋 MESSAGES DE COMMIT — Bonnes pratiques

| Préfixe | Utilisation | Exemple |
|---------|-------------|---------|
| `feat:` | Nouvelle fonctionnalité | `feat: analyse univariée consommation` |
| `fix:` | Correction d'erreur | `fix: corriger gitignore` |
| `add:` | Ajout de fichier | `add: visualisations bivariées` |
| `update:` | Mise à jour | `update: README avec conclusions` |
| `clean:` | Nettoyage | `clean: supprimer fichiers inutiles` |
